# Project Idea

`unity-packages` is a collection of personal Unity game-development packages.

## Intended Role

The packages are intended to provide reusable tools, foundational systems, and architecture for future game-development projects.

## Distribution

Packages are intended to be hosted through a Verdaccio registry.

## Direction

Build package boundaries, public APIs, versioning, and publishing conventions deliberately as each package is introduced. Keep high-level intent here; record current implementation decisions and active work in `.agents/`.
